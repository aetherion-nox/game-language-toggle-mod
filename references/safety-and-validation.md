# 安全与验收：先隔离，再安装同一产物

用于测试、正式安装、平台默认启动、升级和回退。遵守用户已有授权；要求制作 Mod 不等于要求修改平台配置、停用云同步或更换原 EXE。

## 存档边界

识别实际运行实例使用的存档路径，包括系统已知目录、云盘重定向、平台账号子目录、自动档、系统配置和缩略图。路径与账号信息只用于本地验证，不进入发行包。

风险测试前保留必要的当前快照，记录文件清单、大小和可靠哈希。不要假定旧备份就是最新进度，也不要机械要求每次启动完整备份；一次性安装备份、只读基线或更强隔离按用户意图及风险选择。

优先用隔离测试副本、受支持的独立用户数据目录或其他可验证方式，防止测试写入唯一正式档。仅设置一个“测试目录”变量不证明游戏真的使用它：验证真实读写目标，必要时用写入阻断和只读对照。不得将私人试玩进度自动回写正式档。

切换不应改剧情指针、游戏变量、存档格式、语句身份或历史事件。缩略图丢失须单独核查路径／命名／资源版本／缓存，不能因能读档就判定无回归，也不能先覆盖存档碰碰运气。资源回退不应自动回滚之后产生的新存档。

## 有意义的验收矩阵

| 层次 | 代表性检查与证据 |
| --- | --- |
| 资源 | 命名空间重复 ID、缺失译文、跨版本差异、参数与控制码；最终压缩／加密／编译产物可读回，未授权字段保持原样 |
| 生命周期 | 首次进入、初始化前按键、动画／等待时切换、关闭重开、销毁换场景；原循环真实暂停／恢复和异常保持 |
| 独立消费者 | 正文成功而 Log 失败；当前行更新与完整历史更新分开；局部游标刷新不能掩盖旧语言历史 |
| 输入 | 前台／失焦、短按／长按去抖、连续往返、多个循环不重复消费、文本输入／覆盖层冲突 |
| 真机显示 | 原语言→另一语言→原语言；当前句、后续句、多条历史、滚动末尾、字体和长句；关闭返回与所选语言一致 |
| 旧档与回归 | 读取旧档、原菜单／选项／配音语义、缩略图与历史身份；不意外追加历史、不推进剧情；测试外正式文件哈希对照 |
| 安装事务 | 版本不符、同名未知文件、备份失败／为空、部分替换失败、清单提交失败；安装与恢复不碰存档内容 |

按本次范围选择场景，不用矩阵扩大到用户没要求的系统。原生渲染替身永远有方法、空函数总返回、测试只改全局 locale，均不能证明真正的窗口可用。发现回归先确认阶段并恢复最后已验证的 Mod 版本；多次失败先重新评估接入架构，不叠加猜测修补。

自动输入可能短于游戏采样周期。先确认事件被收到；实体键盘反馈可作为证据，标明由谁确认。实机未检查的分辨率、语言、自动／跳过、分支与场景逐项列出，不宣称全游戏无风险。

## 正式安装事务

1. 记录待安装产物的哈希、游戏版本与验收来源。正式安装必须使用实机验收的相同字节；后续重新编译、去诊断或改脚本后应重新验证受影响路径，不能沿用旧包的通过结论。
2. 确认实际游戏进程和资源编辑器已退出；不热替换加载中的文件，不强杀有未保存进度的游戏。需要时用可靠占用／独占检查防止并发启动。
3. 检查目标版本与补丁归属，不覆盖未知修改。先备份会替换的文件、旧清单和按风险需要的最新存档；本应存在的存档未发现、备份为空或校验失败时停止，不能打印“备份成功”。
4. 预备临时文件，校验后只替换清单内最小资源；读回已安装文件，最后提交一致的安装清单。提交前失败应还原已替换资源；提交后终端输出失败不能只回滚脚本却留下新清单。
5. 复核安装文件与正式存档基线，保留不含私人数据的验收结果。测试副本结束时的“未改变”只证明该轮，安装后仍须独立验证。

多文件替换无法原子提交时，持久记录事务阶段、备份位置和每个文件的新旧哈希；保留清单提交点。遇到断电／进程中断遗留事务，下一次操作先验证现场再完成或回退资源与清单，不能把半安装状态识别成未知文件直接覆盖。恢复入口不恢复存档快照，不静默覆盖后续游玩进度。

## 平台启动与交付

只有用户要求时才接入 Steam 或其他平台默认启动。优先沿用官方启动链或受支持参数；原生加载器／代理仅在必要且授权时引入，职责最小、版本不符时安全拒绝，不自动新增存档劫持、云同步设置或每次备份阻塞。不能仅凭启动器出现就称正文／Log 挂载成功。

交付注明：覆盖语言与界面、热键及冲突检查依据、支持版本、产物哈希、隔离与正式验证分别通过哪些项目、剩余限制、升级／卸载／回退和可清理目录。核心目标是逐个显示消费者的正确性，不用语言表条数或单张截图冒充覆盖率。

发行包不含原游戏、原语言包、未经许可字体、私人存档／账号与完整日志；适配代码也应去除本机绝对路径、固定地址和专属于某版本的运行假设。明确这是需按游戏调查适配的技能，不是“一键安装即可支持所有游戏”的承诺。
